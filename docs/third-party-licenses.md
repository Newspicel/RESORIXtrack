# Third-party licenses and notices

RESORIXtrack is licensed under `AGPL-3.0-or-later` (a commercial license is available, see [LICENSING.md](../LICENSING.md)). It is built on the open-source components listed below. This page states what each license requires from an operator or redistributor and how RESORIXtrack meets it. The package tables are generated by `scripts/licenses.py`, which also runs in the test suite and fails when a new dependency carries a license outside the reviewed allow-list.

## What the licenses require, and what we do

| License family | Components | Obligations when distributing | How it is met |
|---|---|---|---|
| **MIT, ISC, BSD-2/3, 0BSD, MIT-0, MIT-CMU, PSF, Unlicense, CC0, BlueOak** | almost everything (Flask, SQLAlchemy, Preact, Astro, gunicorn, openpyxl, WeasyPrint, …) | keep the copyright and license notice with the code | the license files ship inside the packages in the Docker image (`site-packages/*.dist-info/LICENSE*`) and in `node_modules`; nothing is modified |
| **Apache 2.0** | Swagger UI (vendored), cryptography (Apache *or* BSD), packaging, zopfli | keep the license and any `NOTICE` file; state changes (none made) | `frontend/public/vendor/swagger-ui/LICENSE` and `NOTICE` are copied at build time and served with the API docs; the Python packages carry their own license files |
| **SIL Open Font License 1.1** | Inter (via `@fontsource-variable/inter` in the pages; `fonts-inter` in the image for PDFs), DejaVu (Bitstream Vera license) | ship the font license with the font files; do not sell the fonts on their own; a modified font may not use the reserved name | the OFL text is copied to `frontend/public/vendor/fonts/inter-LICENSE.txt` at build time; Debian's `fonts-inter` and `fonts-dejavu-core` packages carry their copyright files in `/usr/share/doc`; the fonts are unmodified |
| **MPL 2.0 / MPL 1.1** | lightningcss (build tool only), Pyphen (tri-licensed MPL 1.1 / LGPL 2.1+ / GPL 2+, used as MPL) | provide the source of the MPL-covered files if modified | not modified; lightningcss is not shipped to browsers at all |
| **LGPL 2.1+ / LGPL 3** | Pango, HarfBuzz, Fontconfig, GLib and friends as Debian packages, dynamically linked by WeasyPrint | allow relinking; provide the library source on request | the libraries are unmodified Debian packages in the image, dynamically linked; their source is at `deb.debian.org` |
| **Debian base image** (`python:3.14-slim`, build stage `node:24-slim`) | the operating-system layer | Debian's own licenses (mostly GPL/LGPL/BSD for OS tools) | unmodified official images; Debian keeps every package's license in `/usr/share/doc/*/copyright` |
| **Apache 2.0 (Caddy)**, **MIT (Mailpit)** | optional TLS proxy (`docker compose --profile tls`), development mail catcher | as above | pulled as unmodified official images; not part of the RESORIXtrack image |
| **CC-BY-4.0** | caniuse-lite browser data (build time only) | attribution | not distributed; used by the build |

None of these licenses is a strong copyleft that would reach RESORIXtrack itself, and all are compatible with AGPL-3.0 (Apache 2.0 is compatible with GPL **3**, not GPL 2). RESORIXtrack ships no modified third-party code.

RESORIX, RESORIXtrack and the RESORIX logos (`brand/`, `backend/resorixtrack/static/brand/`, the default email logo) are trademarks of RESORIX AG. They are **not** licensed under the AGPL. An unmodified RESORIXtrack may show them; a modified or rebranded version must replace them with its own (Settings → Branding, or the files in `brand/`).

## Keeping this page current

```bash
.venv/bin/python scripts/licenses.py --write    # after make lock or npm install
.venv/bin/python scripts/licenses.py --check    # what the test suite runs
```

A new dependency with a license outside the allow-list fails the check; add it to `ALLOWED` in `scripts/licenses.py` only after reading its terms and, if needed, extending the table above.
